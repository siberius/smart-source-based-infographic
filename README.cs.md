# Infografika z pramenů

Žák převede doložené údaje a vztahy z pramenů do editovatelné časové osy, mapy aktérů nebo srovnání. Pro SŠ, zejména pro humanitní předměty.

## Jak použít prompt

1. Otevřete [český prompt](cs/infografika-z-pramenu.md) a vložte jeho obsah jako první zprávu do chatu.
2. Doplňte výukovou otázku, ročník, ověřené podklady s označením zdrojů, formát a způsob použití.
3. Projděte návrh a upravte dokument. Stažitelný DOCX závisí na nástrojích chatu. Náhradní výstup je Markdown pro textový editor.

Na ose můžete odlišit, kdy se událost stala a kdy o ní někdo napsal. U stromu zůstává u každé spojnice doklad.

## Příklad

Z kroniky a dobového tisku vznikne časová osa proměn města. Doložená data mají odkaz na pramen, přibližná jsou označená.

## Stav a soukromí

Verze 1.2.0. Chování v konkrétních modelech ani tvorba příloh zatím nemají doložený test. Repozitář obsahuje textový postup. Podklady zpracovává poskytovatel zvoleného chatu. Používejte veřejné nebo anonymizované materiály.
